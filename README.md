# ROS 2 Drone Development: Design, Construction, and Autonomous Flight
This repository documents my journey of building a ROS 2-based drone, created as a hands-on way to deepen my understanding of robotics, ROS 2, and real-world robotic systems. The main goal is not only to develop a working drone, but to truly understand what is happening behind every component and decision along the way.

The frame is based on an existing design I found on YouTube and recreated in SolidWorks, while the electronic selection, system integration, and software stack are developed from scratch. The project combines both simulation and real-world testing.

At this stage, the focus is on achieving reliable autonomous flight, starting with waypoint navigation and gradually moving toward more advanced capabilities such as SLAM, mapping, and object detection and tracking. Future iterations will expand the system into a more complete autonomous platform.

A key aspect of this project is keeping external assistance to a minimum, using it mainly as a reference tool, in order to learn by facing challenges directly and building a deeper understanding through problem-solving.
